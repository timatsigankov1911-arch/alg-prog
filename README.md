## 🚀 Как использовать

1. Клонируйте репозиторий:

   ```bash
   https://github.com/timatsigankov1911-arch/alg-prog
   ```

2. Перейдите в нужную папку:

   ```bash
   cd "ЛР/ЛР1"
   ```

3. Запустите нужный файл:

   ```bash
   # Python
   python main.py

   # Pascal (Free Pascal)
   fpc main.pas && ./main
   ```

4. Изучайте материалы, выполняйте задания
