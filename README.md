## 🛠 Технологии

В лабораторных работах используются два языка программирования:

- **Python** 🐍 — для практических заданий и алгоритмов
- **Pascal** 🧱 — для классических задач по алгоритмизации

## 🚀 Как использовать

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/tortikghst/Osnovi_algoritmiii-program.git
   ```

2. Перейдите в нужную папку:

   ```bash
   cd "ЛР/ЛР1"
   ```

3. Запустите нужный файл:

   ```bash
   # Python
   python main.py

   # Pascal (Free Pascal)
   fpc main.pas && ./main
   ```

4. Изучайте материалы, выполняйте задания и не забывайте поливать цветочки 🌷
